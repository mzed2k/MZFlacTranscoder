# MZFlacTranscoder
Copilot said:  MZ FLAC, WAV &amp; MP3 Transcoder ist ein portables Windows-Tool zur Konvertierung von FLAC- und WAV-Dateien in FLAC, MP3 und WAV. Unterstützt rekursive Ordnerverarbeitung, Playlists, Cover-/PDF-Übernahme sowie konfigurierbare Audioeinstellungen über eine INI-Datei.
